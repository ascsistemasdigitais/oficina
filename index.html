Backup e Restauração de Dados

Fazer Backup

Baixe todos os dados do sistema (clientes, veículos, ordens de serviço, usuários) em um arquivo JSON seguro.

Guarde este arquivo em local seguro (Pen Drive, Google Drive, etc.)

Restaurar Backup

Restaure os dados a partir de um arquivo de backup (.json) anteriormente criado.

Isso substituirá TODOS os dados atuais no banco de dados!

Dicas Importantes de Segurança:

  • Faça backup semanalmente ou após cada dia de trabalho intenso.
  • Guarde cópias em múltiplos locais (computador + Pen Drive + nuvem).
  • Nomeie os arquivos com datas (ex: backup-2026-01-15.json) para facilitar a organização.
  • CRÍTICO: Este backup agora salva os dados da nuvem, garantindo que você tenha uma cópia de segurança externa.
